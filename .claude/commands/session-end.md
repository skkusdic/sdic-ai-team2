# 세션 종료 체크리스트

다음 단계를 순서대로 실행해줘.

## 1. 변경된 파일 목록 확인
```
git status
git diff --stat HEAD~5..HEAD
```
스테이징 안 된 파일, 커밋 안 된 변경사항 있으면 따로 표시해줘.

## 2. Push 안 된 파일 확인
```
git log origin/main..HEAD --oneline
```
로컬에만 있고 push 안 된 커밋이 있으면 목록과 함께 경고해줘.

## 3. 완료 / 미완료 작업 정리
이번 세션에서 대화한 내용을 바탕으로 아래 형식으로 정리해줘:

**완료:**
- (이번 세션에서 실제로 완성하고 push까지 한 작업)

**미완료 / 확인 필요:**
- (코드는 썼지만 테스트 안 한 것, 에러 났던 것, 주석으로 TODO 남긴 것)

## 4. 다음 세션 할 일 3가지
지금 프로젝트 상태와 6주 일정을 기준으로 우선순위 높은 것 3가지만 골라줘.
형식:
1. [파일명] 할 일 — 이유
2. [파일명] 할 일 — 이유
3. [파일명] 할 일 — 이유

## 5. memory.md 업데이트
프로젝트 루트의 `memory.md` 파일에 오늘 날짜로 아래 형식의 요약을 추가해줘.
파일이 없으면 새로 만들어줘.

```
## YYYY-MM-DD
- 완료: (한 줄 요약)
- 미완료: (한 줄 요약)
- 다음: (다음 세션 첫 번째 할 일)
```
